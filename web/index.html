関数的平方根 計算ツール

g(g(x)) = f(x) となる g のテイラー展開を、厳密計算（分数・根号）で求めます。m 乗根や f[3/2] のような分数回反復にも対応しています。
Exact Taylor series of the functional square root (half-iterate) g∘g = f, iterative roots and fractional iterates.

使えるもの：x, 数（分数・小数）, + − * / ^, 括弧, e^(…), exp, log（自然対数）, sqrt, sin, cos, tan, sinh, cosh, tanh, asin, acos, atan, asinh, acosh, atanh, pi。掛け算の * は 2x のように省略できます。

グラフ

f(x)（青）と g(x)（緑）、それに g(g(x))（赤の破線）を重ねています。赤が青に重なるほど、関数的平方根として正しく求まっています。級数は x=0 のまわりの近似なので、0から離れるとずれます。

前提：f(0) = 0、f′(0) ≠ 0。計算は api.naisu.moe（sympy による厳密計算）で行っています。元のPython実装：n2y6/func_sqrt

関数的平方根とは

関数 f に対して、2 回合成すると f になる関数 g（g(g(x)) = f(x)）を f の関数的平方根（半反復, half-iterate）といいます。たとえば sinh x の関数的平方根は x + x3/12 − x5/160 + … と展開されます。同じように、m 回合成して f になる g を関数的 m 乗根、それを p 回合成したものを分数回反復 f[p/q] と呼びます。

このツールは、x = 0 が不動点（f(0) = 0）で f′(0) ≠ 0 の関数について、g = b1x + b2x2 + … とおいて係数を低い次数から順に決めていきます。b1 は f′(0) の m 乗根で、bn は xn の係数を比べると一次方程式で決まります。計算は分数と根号のまま行うので、浮動小数点の誤差はありません。
